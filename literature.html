Each file is {venue, release, label, papers}. The loops below merge every release and sort newest first by sort_key. Every field comes from third-party metadata, so each one goes through `escape` and none through `markdownify`. Authors: up to four are listed; longer lists show the first author's family name and "et al." (e.g. "Devic et al."), with the full list inside the abstract panel.
